# Personal Portfolio – Frontend Developer

Proyecto desarrollado como portafolio personal, con el objetivo de presentar mis habilidades, proyectos y enfoque como desarrolladora Frontend. Construido con intención en el detalle, enfoque en experiencia de usuario y estética limpia.

Incluye una interfaz moderna, responsive y un formulario de contacto funcional.

## Tecnologías

- React
- Vite
- JavaScript (ES6)
- HTML5
- CSS3 (custom styling)
- EmailJS (integración de formulario)

---

## Funcionalidades

La aplicación permite:

- Diseño responsive
- Interfaz moderna con efectos visuales (glassmorphism)
- Animaciones suaves
- Formulario de contacto funcional con envío real de mensajes

---

## Cómo ejecutar

1. Descargar o clonar el repositorio.
2. Instalar las dependencias:

```bash
npm install
```

3. Ejecutar el proyecto:

```bash
npm run dev
```

---

## Notas

- El formulario de contacto está integrado con EmailJS, permitiendo el envío de mensajes sin necesidad de backend.
- Las variables de entorno (.env) no están incluidas en el repositorio por seguridad.
- El diseño fue desarrollado con enfoque en claridad visual, accesibilidad y experiencia de usuario.
